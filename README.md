# Assignment-Navigation-bar

# College Web Development Project

This project is a collection of HTML and CSS webpages created as part of my college web development practice at **Dezyne École College**.

## 📁 Project Files

* `project(1).html` — Project webpage
* `aboutus(1).html` — About Us webpage
* `achievement.html` — Achievements webpage
* `contactus(1).html` — Contact Us webpage

## ✨ Features

* Full-screen webpage layouts
* CSS gradient backgrounds
* Centered navigation menu
* Rounded navigation bar
* Flexbox-based layout
* Interactive hover effects
* Navigation links between different website sections
* Clean and simple HTML/CSS design

The webpages use a full-screen `.box` layout with Flexbox for centering and different gradient backgrounds.

The navigation menu contains links for **Home, About Us, Project, Achievements, and Contact Us**.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Gradients
* CSS Hover Effects

## 🎯 Purpose

The purpose of this project is to practice the fundamentals of **web development**, including:

* Creating webpage structures with HTML
* Styling webpages using CSS
* Using Flexbox for layouts
* Creating navigation menus
* Applying gradients and visual effects
* Adding hover interactions
